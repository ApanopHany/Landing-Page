# Landing Page — الأستاذ أحمد عبد المعز

موقع عربي متجاوب باتجاه RTL، باستخدام HTML وCSS وJavaScript بدون مكتبات خارجية.

## الملفات
- `index.html`: الصفحة الرئيسية.
- `assets/ahmed-abdelmoez.png`: صورة الأستاذ الشخصية.

## ملاحظات
- صفوف الدراسة لا تظهر إلا بعد الضغط على المرحلة.
- الضغط مرة ثانية على المرحلة المفتوحة يخفي صفوفها.
- لا يتم اختيار صف تلقائيًا.
- بطاقة «سلسلة المعز — معاك خطوة بخطوة» تظهر أسفل الصورة.
- رقم واتساب: `201011405049`.

## النشر على GitHub Pages
1. ارفع `index.html` وملف `README.md` ومجلد `assets` إلى جذر المستودع.
2. افتح Settings → Pages.
3. اختر Deploy from a branch، ثم `main` والمجلد `/(root)`.
4. اضغط Save وانتظر ظهور رابط الموقع.
